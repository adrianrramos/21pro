# Bundled CardMeister artwork

These 53 offline SVGs are exported from the **full** CardMeister implementation: all 52 French-suited cards, including 12 distinct court illustrations, plus the CardMeister card back.

- Source page: <https://cardmeister.github.io/index.html?full>
- Source repository: <https://github.com/cardmeister/cardmeister.github.io>
- Export source: [`elements.cardmeister.full.js`](https://github.com/cardmeister/cardmeister.github.io/blob/0ce99ba7d497ffdcd25d6c0c4133f1193ab4fb6b/elements.cardmeister.full.js)

The SVGs were generated offline from the upstream full JavaScript card generator by instantiating each card identifier (`Ac` through `Ks`) and `back`, then saving the generated `data:image/svg+xml` payloads as standalone SVG files. No runtime network access or webview is required by 21 Pro.
